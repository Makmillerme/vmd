# docs

Отримати **актуальну документацію** бібліотеки або API з контексту задачі.

## Для VMD Extractor

1. Визнач бібліотеку з контексту; прочитай версію у [`requirements.txt`](../../requirements.txt).
2. Основні залежності: `pandas`, `openpyxl`, `aiosqlite`, `python-dotenv`, `aiohttp`, `Pillow`.
3. Відкрий офіційну доку через **WebFetch** / `web_search`.
4. Застосуй до коду в `vmd_extractor/`.

## Не застосовується

- `package.json`, Next.js, shadcn — немає в цьому репо.

Ця команда доступна в чаті як /docs
